  - `config.platform.php` di composer.json di-set 8.4.27, `composer.lock` disinkronkan tanpa menugbah versi package

  - PHP lokal (Laragon) disamakan ke 8.4.27
  - Proses di server production dan dev:
    1. Naikkan PHP server ke 8.4.27, cek dengan `php -v`
    2. `git pull` perubahan composer.json dan composer.lock
    3. `composer install --no-dev --optimize-autoloader` (install sesuai lock, bukan `update`)
    4. `php artisan optimize:clear` lalu `php artisan optimize`
    5. Restaart PHP-FPM dan queue wroker, cek halaman login dan dashboard
  - `composer audit` di production: 27 advisory di 7 package (commonmark, guzzle, psr7, http-foundation, livewire, framework, flysystem), belum diperbaiki
