## Catatan

- **Status modul Partnership:** data pitching, kontak, dan master (wilayah, ursuan, produk, OPD) udah bisa ditarik dari sistem Partnership lama, dengan akses sesuai role
- **Kendala:** data lama gak selalu rapi, jadi tiap migrasi ETL butuh pengecekan manual
- **Rencana:** migrasi penuh data pitching mulai awal Juni 2026
- **Perintah ETL:**

```
## dev server
# dump data
mysqldump -u partnership -p -h 127.0.0.1 --port=3306 --single-transaction --no-create-info partnership | gzip > partnership_data_only.sql.gz
# hapus file dump
rm -f partnership_data_only.sql.gz partnership_table.sql

## lokal
# unduh dump
scp partnership@ssh-hosting.smartid.co.id:/home/partnership/partnership-app/partnership_data_only.sql.gz .

# ETL
php artisan migrate:fresh --seed
php artisan sync:master              # urusans, provinces, regencies, opds, products
php artisan sync:contacts            # kontak dari partnership DB
php artisan sync:cards --year=2026   # migrasi rencana_pitchings 2026 → cards
```
